# MyPortfolio

Personal portfolio website showcasing my projects, cybersecurity experience, certifications, research, and journey as a Computer Science student.

## Built with

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **Vercel**

## Getting Started

First, install the dependencies:

```bash
pnpm install
```

Then, run the development server:

```bash
pnpm dev
```

Open http://localhost:3000 with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page will automatically update as you make changes.

## Deployment

This project is deployed with Vercel. Every push to the `main` branch automatically triggers a new production deployment.

## Project Structure

```text
app/          # Application pages and layouts
components/   # Reusable UI components
public/       # Static assets, images, and logos
styles/       # Global styling
```
